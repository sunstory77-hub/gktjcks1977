# SNS 콘텐츠 스튜디오

상세페이지 · 인스타 피드 · 릴스/쇼츠 · 유튜브 썸네일을 한 곳에서 만들고 **PNG/JPG 이미지**와 **슬라이드 영상(MP4/WebM)**으로 내보내는 브라우저 편집 도구입니다. 서버 없이 브라우저 안에서만 동작하며, 작업은 브라우저(IndexedDB)에 자동 저장됩니다.

## 지원 포맷

| 포맷 | 크기 | 용도 |
|---|---|---|
| 인스타 피드 1:1 | 1080×1080 | 정사각 피드·캐러셀 |
| 인스타 피드 4:5 | 1080×1350 | 카드뉴스·공지 |
| 릴스·쇼츠·스토리 9:16 | 1080×1920 | 세로 영상·커버 |
| 유튜브 썸네일 16:9 | 1280×720 | 유튜브·강의 썸네일 |
| 상세페이지 | 860×가변 | 섹션을 이어붙인 세로 상세페이지 |

## 주요 기능

- **템플릿 9종**: 카드뉴스 3장, 사진+카피, 후기 카드, 모집 공지, 쇼츠 슬라이드 영상, 릴스 커버, 유튜브 썸네일 2종, 상세페이지 풀세트(6섹션)
- **편집**: 텍스트(글꼴 5종·외곽선·그림자·글자 배경) / 사진(꽉 채우기·밝기·대비·채도·흑백·흐림·둥근 모서리) / 도형(사각·원·그라데이션)
- 드래그 이동, 모서리 크기 조절(Shift: 비율 유지), 중앙 스냅, 레이어 순서·숨김·잠금
- 사진을 캔버스로 끌어다 놓으면 추가, 빈 사진 칸 위에 놓으면 교체
- 여러 페이지(캐러셀/섹션/장면) 추가·복제·순서 변경
- 실행취소/다시실행 (Ctrl+Z / Ctrl+Shift+Z), 복제 (Ctrl+D), 삭제 (Delete), 화살표로 미세 이동
- **내보내기**
  - 현재 페이지 / 전체 페이지 PNG·JPG
  - 상세페이지: 모든 섹션을 **한 장의 긴 이미지**로
  - 영상: 페이지별 길이·전환(페이드/슬라이드)·모션(줌인/줌아웃/이동) + 배경음악
  - 프로젝트 JSON 백업·불러오기
- 파일명 규칙: `[작업명]_[YYYYMMDD]_[번호].png`

## 실행 방법

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 에 정적 파일 생성 (어느 웹호스팅에나 업로드 가능)
```

## 테스트

```bash
npm test                    # 단위 테스트 (줄바꿈, 영상 타임라인, 템플릿 배치, 파일명 등)
npm run build && npm run e2e  # 실제 크롬으로 편집·내보내기 전 과정 검증
```

e2e는 `playwright-core`를 쓰며 크롬 경로를 `CHROMIUM_PATH` 환경변수로 지정할 수 있습니다.

## 참고

- 영상은 **실시간 녹화** 방식이라 영상 길이만큼 시간이 걸립니다.
- 최신 크롬은 **MP4(H.264)**로 저장되어 인스타·유튜브에 바로 올릴 수 있습니다. MP4 녹화를 지원하지 않는 브라우저에서는 WebM으로 저장됩니다(내보내기 창에 저장 형식 표시).
- 폰트(Noto Sans KR, Black Han Sans, 주아, 나눔명조, 고운돋움)는 앱에 포함되어 오프라인에서도 동일하게 렌더링됩니다. 모두 OFL 라이선스로 상업적 이용이 가능합니다.

    templates.ts   템플릿
    render.ts      캔버스 렌더러
    text.ts        한글 줄바꿈
    timeline.ts    영상 타임라인·모션
    export.ts      PNG/상세페이지/영상 내보내기

tests/         단위 테스트
e2e/           브라우저 스모크 테스트
