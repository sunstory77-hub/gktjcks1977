# 홍보공장 앱 (판매용 제품)

회사가 **회사 정보·브랜드 킷·AI API 키를 한 번 등록**하면, 캠페인 1건(교육·행사 / 상품 / 서비스·매장)의 팩트 시트로 카피 3안·카드뉴스·인스타 광고·상세페이지·15초 릴스·AI 이미지를 만들고 ZIP으로 내려받는 웹 서비스입니다.
사업기획서: `../docs/홍보콘텐츠플랫폼_사업기획서_20260928.docx`

## 판매 준비 기능

| 기능 | 내용 |
|---|---|
| 업종 범용화 | 캠페인마다 **교육·행사 / 상품 판매 / 서비스·매장** 선택. 라벨·필수 항목·카드 제목·릴스 문구·AI 프롬프트·자리표시자·자료 가져오기가 업종에 맞게 바뀜 (예: 상품은 강사→브랜드, 커리큘럼→주요 특징, 수강료→가격, 일시·브랜드는 선택) |
| 이미지 보관함 | 캠페인당 12장. 사진 올리기 + AI 생성을 여러 장 모아 두고 **세로 자리(릴스·스토리 광고)** 와 **피드 자리(카드뉴스·피드 광고·상세페이지 표지)** 에 골라 배정. 한쪽만 있으면 같은 사진 사용 |
| AI 이미지 | 스타일 9종(강의 현장·행사·책상 소품·상품 연출 무대·일상·매장·카페·자연·추상, 업종별 추천 순서), 비율(9:16·4:5·1:1), **추가 설명**(150자), **상품 사진 연출**(올린 상품 사진을 참고로 장면에 배치) |
| 결과물 유지 | 카드뉴스·광고·상세페이지·릴스 결과를 DB에 기록 → 서버를 다시 켜도 그대로 보이고 ZIP으로 받음 |
| 문안 직접 수정 | 카피·광고 문구·상세페이지를 화면에서 고침. 글자 수 한도(레이아웃) 검사, 광고 표현 검수 다시 실행, 고친 결과로 이미지 다시 만듦 |
| 가입 동의 | 이용약관·개인정보처리방침(AI 회사 국외 이전 고지 포함) 동의 필수, 동의 시각·버전 저장. 문서는 `/terms.html`, `/privacy.html` (**초안 — 법률 검토 필요**) |
| 팀원 | 소유자가 초대 링크(7일·1회용) 생성 → 팀원 가입 → 같은 회사 캠페인 공유. 회사 정보·브랜드·API 키·팀원 관리는 소유자만 |
| 요금제 | 체험(14일·월 캠페인 3·팀원 2) / 베이직(월 30·팀원 3) / 프로(월 200·팀원 10) [수치 초안, 확인 필요]. 기간이 끝나면 새로 만들기·생성만 막고 보기·ZIP은 허용 |
| 계정 | 비밀번호 변경(다른 기기 로그아웃), 재설정 링크, 탈퇴(소유자는 회사 데이터 전체 즉시 삭제) |
| 운영 | `/healthz`, 보안 헤더(CSP·X-Frame-Options 등), 만료 세션 정리, 종료 신호 처리, 프록시 뒤 실제 IP(`TRUST_PROXY`) |

## 운영자 도구 (결제·메일 연동 전 수동 운영)

```bash
cd app
node src/admin.js list                              # 회사·요금제·이번 달 캠페인 수
node src/admin.js set-plan owner@회사.kr basic 1     # 요금제 지정(개월 생략 시 기간 없음)
node src/admin.js reset-link user@회사.kr            # 1시간짜리 비밀번호 재설정 링크 (APP_URL 기준)
node src/admin.js backup /backup                     # DB 온라인 백업 + 회사 파일 복사
```

## 실행

```bash
cd poc && npm install      # 렌더 엔진(카드뉴스·릴스·AI) 의존성
cd ../app && npm install
npm start                  # http://127.0.0.1:5180 (PORT, HOST로 변경)
npm test                   # 앱 테스트 (엔진 테스트는 poc에서 npm test)
```

- Node.js 22.5 이상 (내장 `node:sqlite` 사용)
- 데이터: `app/data/` 또는 `DATA_DIR` (DB·회사별 로고·캠페인 파일). git에 올라가지 않습니다.

| 환경 변수 | 설명 |
|---|---|
| `APP_MASTER_KEY` | API 키 암호화용 32바이트 base64. **운영(`NODE_ENV=production`)에서는 필수.** 잃어버리면 저장된 API 키를 복호화할 수 없으므로 따로 보관 |
| `DATA_DIR` | 데이터 폴더 (기본 `app/data`) |
| `COOKIE_SECURE=1` | HTTPS 배포 시 세션 쿠키 Secure + HSTS |
| `TRUST_PROXY=1` | 리버스 프록시 뒤에서 `X-Forwarded-For`로 로그인 제한 IP 판단 |
| `APP_URL` | 운영자 도구가 만드는 링크의 주소 |

## 배포 (Docker)

```bash
echo "APP_MASTER_KEY=$(openssl rand -base64 32)" > .env   # 저장소 루트에서
docker compose up -d --build                             # 127.0.0.1:5180, 데이터는 promo-data 볼륨
```

- 이미지에 Chromium(릴스 렌더)·한글 글꼴 포함, `HEALTHCHECK`는 `/healthz`
- HTTPS는 앞단 리버스 프록시(Caddy·Nginx·클라우드 LB)에서 처리
- 검증 범위: 이미지 빌드(npm 설치)·컨테이너 실행·`/healthz`·마스터 키 없으면 시작 거부까지 확인. Chromium·글꼴 설치(apt) 단계는 개발 환경 네트워크 제한으로 확인하지 못했으므로 **운영 서버에서 첫 빌드 후 릴스 1건 렌더로 확인 필요**
- 저장소에 `package-lock.json`이 없어 빌드마다 의존성 버전이 달라질 수 있습니다(잠금 파일 추가 권장)
- 서버 1대·SQLite 기준입니다. 여러 대로 늘릴 때 Postgres·Redis(렌더 큐)로 전환

## 사실 보호 (판매용 핵심)
- AI는 사실 정보를 `{{일시}}`·`{{가격}}` 같은 업종별 자리표시자로만 쓰고 프로그램이 채웁니다. 조사는 받침에 맞게 고칩니다.
- 팩트 시트에 없는 숫자는 오류. 한 자리 순서·개수("3가지")는 허용하되 단위가 붙으면("3배", "9명") 검사합니다.
- 글자 수는 채운 뒤 길이로 재고, 어기면 1회 다시 생성, 그래도 어기면 입력 문구로 대체하고 경고합니다.
- AI 이미지 요청에는 제목·부제·대상만 보내고 일시·가격·강사명은 보내지 않습니다. 구체적 상품·메뉴를 지어내는 스타일은 두지 않았고, 상품은 실제 사진을 참고로만 연출합니다.

## 보안 설계

| 항목 | 구현 |
|---|---|
| 회사 간 격리 | 모든 캠페인·이미지·파일 조회에 세션의 회사 ID 조건. 다른 회사 ID는 404 |
| 역할 | 소유자 / 팀원. 회사 정보·브랜드·키·팀원 관리는 소유자만(403) |
| API 키 | AES-256-GCM, 회사 ID·공급자를 AAD로 묶음. 화면엔 끝 4자리만, 브라우저로 다시 보내지 않음 |
| 비밀번호 | scrypt + salt, 상수 시간 비교. 변경·재설정 시 다른 로그인 끊음 |
| 세션·링크 | 무작위 토큰, DB엔 SHA-256만. 세션 14일, 초대 7일, 재설정 1시간(1회용) |
| CSRF·헤더 | 변경 API는 `x-requested-with` 필수. CSP(같은 출처만), X-Frame-Options DENY, nosniff |
| 로그인 | 같은 IP·이메일 15분에 10회 실패 시 429 |
| 업로드 | 시그니처 확인 후 ffmpeg 재인코딩(메타데이터 제거) |
