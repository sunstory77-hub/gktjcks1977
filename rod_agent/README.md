# 로드 업무 에이전트 v2.0 — 사용설명서

요청하면 Claude가 **완성본을 쓰고**, 바로 **HWPX·PPTX·DOCX·XLSX 파일로 만든 뒤 검증**까지 하는 내 PC 전용 업무 도구입니다.
로드 지시서 v5.0(결론 먼저, `[전제]`, `[재정의]`, 출처·`[추정]`, `[기준: YYYY-MM / 확인 필요]`, 트리거 명령)이 시스템에 내장되어 있습니다.

---

## 1. 설치 (처음 1회)

1. **Python 3.10 이상** 설치: https://www.python.org/downloads/
   설치 첫 화면에서 **"Add python.exe to PATH"를 반드시 체크**하세요.
2. 이 `rod_agent` 폴더를 **고정 위치에 둡니다.** 추천: `C:\RodAgent`
   > ⚠ 지금 쓰시는 bat은 `AppData\Roaming\Claude\local-agent-mode-sessions\...\outputs` 안의 파일을 실행합니다. 그 폴더는 Claude 작업 세션의 임시 폴더라서 정리될 때 에이전트도 함께 사라질 수 있습니다.
3. `AI_Agent_Start.bat`을 더블클릭하세요.
   - 처음 실행할 때 가상환경을 만들고 패키지를 설치합니다(1~3분).
   - 다음부터는 설치 단계를 건너뛰고 바로 켜집니다.
4. 브라우저가 열리면 **⚙ 설정**에 Anthropic API 키(`sk-ant-...`)를 입력하고 저장합니다.
   API 키 발급: https://console.anthropic.com → API Keys

> 바탕화면 바로가기: `AI_Agent_Start.bat` 우클릭 → 보내기 → 바탕 화면에 바로 가기 만들기

## 2. 사용법

| 순서 | 할 일 |
|---|---|
| ① | 왼쪽에서 **업무 모드**를 고릅니다. |
| ② | 필요하면 파일을 **끌어다 놓거나 📎**로 첨부합니다(공고문 PDF, 이력서 DOCX, 명단 XLSX 등). |
| ③ | 요청을 입력하고 Enter를 누릅니다. |
| ④ | 답변이 끝나면 모드에 맞는 파일이 **자동으로 생성·검증**되어 `열기`/`받기` 카드로 나타납니다. |
| ⑤ | 다른 형식이 필요하면 답변 아래의 `HWPX / DOCX / PPTX / XLSX` 버튼을 누릅니다. |

### 업무 모드

| 모드 | 기본 파일 | 이런 요청에 |
|---|---|---|
| ✦ 자유 작업 | (선택) | 요약·정리·질문 등 |
| 🎓 강의·교안 | **PPTX** | 커리큘럼, 강의 슬라이드(발표자 노트 포함) |
| 📋 강사 행정 | **DOCX** | 이력서 정리, 견적서, 계약서, 강의확인서 |
| 🏛️ 정부지원사업 | **HWPX** | 사업계획서, 결과보고서, 공고문 분석 |
| 🎬 콘텐츠 | (선택) | 릴스 대본, 카피, SNS 글 |
| 📊 자료 정리 | **XLSX** | 명단 정리, 중복 제거, 이력 표 |
| ⚙️ 자동화·개발 | (선택) | 스크립트, 프롬프트 |

상단 **파일** 메뉴에서 이번 요청의 형식을 바꾸거나 `만들지 않음`을 고를 수 있습니다.

### 상단 옵션
- **모델**: Opus 5(고품질, 기본) / Sonnet 5(빠르고 저렴)
- **깊이**: 빠르게·보통·깊게 — 깊을수록 느리지만 꼼꼼해집니다.
- **웹검색**: 지원사업 공고, 정책, 가격처럼 최신 정보가 필요할 때 켭니다.

### 트리거 명령 (입력창에 그대로)
| 명령 | 동작 |
|---|---|
| `리셋` | 새 작업으로 시작 |
| `납품` | 설명 없이 문서 본문만 |
| `재검증` | 직전 산출물의 누락·오류 점검 |
| `변형 [대상]` | 예: `변형 중학교 교사용` |
| `축약 [분량]` | 예: `축약 1페이지` |
| `이어서` | 끊긴 곳부터 계속 작성 |

## 3. 파일 규칙

- 저장 위치: 기본 `rod_agent\outputs` (⚙ 설정에서 바꿀 수 있고, `📁 산출물 보기 → 폴더 열기`로 바로 열림)
- 파일명: `[기관명]_[문서종류]_[YYYYMMDD].확장자`, 같은 이름이 있으면 `_v2`, `_v3` 순서로 붙습니다.
- 검증(§7): HWPX는 구조 검증(validate.py와 같은 기준), DOCX·PPTX·XLSX는 다시 열어 손상 여부를 확인하고, XLSX는 오류 셀까지 검사합니다. 실패하면 카드에 `✖ 검증 실패`와 사유가 표시됩니다.

### 첨부파일 지원
| 형식 | 처리 |
|---|---|
| PDF | 원본을 그대로 전달합니다. 표와 스캔본도 판독합니다. |
| 이미지(PNG/JPG/WEBP/GIF) | 원본을 그대로 전달합니다. |
| DOCX · XLSX · PPTX · HWPX · CSV · TXT · MD | 텍스트와 표를 추출합니다. |
| **구형 HWP** | 자동 추출이 안 됩니다. `⚠ 수동 확인 필요`로 표시되며, 한글에서 HWPX나 PDF로 저장한 뒤 다시 올리면 됩니다. |

## 4. 문제 해결

| 증상 | 해결 |
|---|---|
| `Python not found` | Python 재설치 시 "Add to PATH" 체크 |
| 패키지 설치 실패 | 인터넷 연결 확인 후 `.venv` 폴더 삭제하고 다시 실행 |
| `API 키가 올바르지 않습니다` | ⚙ 설정에서 키 재입력 |
| `요청 한도를 초과했습니다` | 1~2분 뒤 재시도, 또는 Sonnet 5로 변경 |
| 8000번 포트 충돌 | `.env`에 `PORT=8010`처럼 다른 번호 지정 |
| 답변이 중간에 끊김 | `이어서` 입력 |
| 이미 켜져 있는데 bat을 또 누름 | 새로 켜지 않고 브라우저만 엽니다(정상 동작). |

종료: 검은 창(서버 창)을 닫으면 됩니다. 대화 기록은 `data\sessions`에 남습니다.

## 5. 폴더 구조

```
rod_agent/
├─ AI_Agent_Start.bat   실행 파일(더블클릭)
├─ server.py            로컬 웹 서버(127.0.0.1 전용, 외부 접속 불가)
├─ agent/
│  ├─ prompts.py        로드 지시서 v5.0 + 업무 모드 정의  ← 모드 추가·수정은 여기서
│  ├─ llm.py            Claude 호출(스트리밍, 웹검색, 거절 시 자동 대체 모델)
│  ├─ extract.py        첨부파일 읽기
│  ├─ markdown.py       답변 구조 분석
│  ├─ render.py         DOCX·PPTX·XLSX 생성 + 검증 + 파일명 규칙
│  └─ hwpx_writer.py    HWPX 생성(보고서 스타일)
├─ assets/hwpx/         한글 문서 템플릿
├─ static/              화면(HTML·CSS·JS)
├─ tests/               자동 테스트 (python -m pytest tests -q)
├─ data/                대화 기록·첨부 원본(자동 생성)
└─ outputs/             산출물(자동 생성)
```
