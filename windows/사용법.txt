홍보공장 — 내 PC 설치판 (Windows 10/11)

■ 처음 한 번
 1. 이 ZIP 파일을 마우스 오른쪽 → [모두 압축 풀기] (예: 문서\홍보공장)
 2. 풀린 폴더에서 [홍보공장_실행.bat] 더블클릭
    - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]
    - 처음에는 준비물을 자동으로 내려받습니다 (인터넷 필요, 5~10분)
 3. 홍보공장 창이 열리면 [회원가입] → 설정에서 Claude·Gemini API 키 등록
 4. 바탕화면에 [홍보공장] 바로가기가 생깁니다. 다음부터는 이것만 누르면 됩니다.

■ 끄기
 - 창을 닫아도 뒤에서 계속 켜져 있습니다. 완전히 끄려면 [홍보공장_종료.bat]

■ 저장 위치
 - 캠페인·결과물·설정: C:\Users\(사용자)\AppData\Local\PromoFactory
 - 이 폴더를 지우면 모든 데이터와 등록한 API 키가 사라집니다.
 - 프로그램 폴더를 새 버전으로 바꿔도 데이터는 그대로 남습니다.

■ 문제가 생기면
 - 검은 창에 빨간 글씨가 나오면 그 화면을 캡처해 보내 주세요.
 - 기록 파일: C:\Users\(사용자)\AppData\Local\PromoFactory\server-error.log
