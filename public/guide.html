DETAIL PAGE AI 사용 안내

상품 사진과 정보를 입력하면 AI가 설명을 정리하고 상세페이지 문구와 연출 이미지를 만들어 줍니다. 만든 뒤에는 블록별로 직접 고치고 JPG로 저장할 수 있습니다.

1. 시작하기

  1. 상단의 API 연결 안 됨을 눌러 내 Gemini API 키를 붙여넣고 연결하기를 누릅니다. 키는 Google AI Studio에서 만들 수 있습니다.
  2. 프로그램을 종료하면 키가 지워집니다. 다시 켜면 새로 연결해 주세요.
  3. 연결 없이도 직접 문구 수정, 순서 변경, 숨김, 사진 교체, 저장은 모두 쓸 수 있습니다.

2. 상품 정보 입력

  • 상품명은 필수입니다. 상품 설명, 타겟 고객, 상품 사진(최대 5장, 장당 10MB)을 입력합니다.
  • 가격·구성/규격·배송 조건·프로모션은 선택입니다. 입력한 것만 상세페이지에 쓰입니다. 프로모션을 비워 두면 프로모션 블록은 숨겨집니다.
  • AI로 정리: 설명을 6개 항목(한눈에 보기, 핵심 특징, 구성·규격, 사용·보관, 구매·배송, 확인할 사항)으로 정리합니다. 결과를 고친 뒤 적용하거나 취소할 수 있고, 적용 후 되돌리기도 가능합니다. 입력한 가격·수량·배송 조건은 보존하며, 없는 효능·인증·원산지·판매 실적은 만들지 않습니다.
  • 정보 검색: Google 검색으로 공개 정보를 찾아 출처와 함께 보여 줍니다. 사진 분석: 사진에서 보이는 내용만 정리합니다. 둘 다 참고용이므로 사실 여부를 직접 확인해 주세요.

3. 생성

  • 일반은 빠르고 가볍게, 고품질은 더 정교하게 만들지만 사용료가 더 듭니다.
  • 생성 전에 외부 전송과 별도 사용료 안내가 나옵니다. 동의해야 진행됩니다.
  • 도중에 취소할 수 있고, 일부 이미지가 실패해도 완료된 결과는 보존됩니다. 실패한 이미지는 다시 시도로 이어서 만듭니다.
  • AI 없이 기본 구성만 만들기는 입력한 내용으로 블록을 채우는 기능이며 API가 필요 없습니다.

4. 편집

  • 각 블록 위의 ▲ ▼로 순서를 바꾸고, 숨기기로 저장에서 뺄 수 있습니다. 숨긴 블록은 복원으로 되돌립니다.
  • 수정을 누르면 문구를 직접 고칠 수 있습니다. AI로 고치기에 요청(예: 더 짧게)을 쓰면 AI가 문구를 고칩니다.
  • 이미지마다 사진으로 교체, AI 수정, 다시 생성, 삭제, 복원이 있습니다. 삭제한 이미지는 화면과 저장본에서 빠집니다.
  • 색상 버튼으로 상세페이지 결과물의 색을 바꿀 수 있습니다(프로그램 화면 색과는 별개).
  • 모든 변경은 자동 저장됩니다. 되돌리기(Ctrl+Z) / 다시 실행(Ctrl+Shift+Z)을 지원합니다.

5. 저장·내보내기

종류설명
전체 상세페이지 JPG가로 860px(고해상도 선택 시 1720px). 매우 길면 여러 개 파일로 나뉩니다.
이미지 ZIP사용 중인 이미지만 담습니다. 숨긴 블록·삭제한 이미지는 제외됩니다.
프로젝트 백업(JSON)입력 내용·편집 상태·이미지를 담습니다. API 키는 포함되지 않습니다.
백업에서 복원JSON 백업을 새 프로젝트로 불러옵니다.

편집 버튼과 이 안내 문구는 JPG·ZIP에 들어가지 않습니다.

6. 다국어 상세페이지 (영어·일본어·중국어 간체)

  • 한국어 원문 하나로 수출 국가별 상세페이지를 만듭니다. 이미지·구성·색상은 공통, 문구만 번역합니다.
  • 미리보기 위 ＋ 번역 언어에서 언어를 고르고 AI 번역을 실행합니다. 번역문은 AI 초안이므로 판매 전에 전문 번역가·현지인 검수를 권장합니다.
  • 번역 수정: 한국어 원문과 번역을 나란히 보며 고칩니다. 이 언어에서만 이미지를 교체하거나 블록을 숨길 수 있습니다.
  • 용어집·시장 정보: 번역어 통일, 번역 금지 용어, 현지 가격·상품명을 지정합니다. 가격은 자동 환산하지 않으니 직접 입력하세요.
  • 전문 번역 검수: [검수 → 검수 패키지 내보내기]로 엑셀(또는 XLIFF)을 만들어 번역가에게 보내고, 돌려받은 파일을 [검수 결과 가져오기]로 확인·적용합니다. 모든 블록이 ‘검수 완료’이면 확인 없이 저장됩니다.
  • 한국어 원문을 고치면 번역에 ‘원문 변경’ 표시가 생깁니다. 확인 후 확정하거나 다시 번역하세요.
  • 저장·내보내기에서 언어를 고르면 파일 이름에 언어 코드(예: _en)가 붙고, 여러 언어는 ZIP으로 묶입니다.

7. 자주 묻는 질문

인증 실패가 나옵니다

키를 다시 붙여넣어 연결해 주세요. 키 앞뒤 공백이나 줄바꿈이 섞이지 않았는지 확인하세요.

사용량 초과가 나옵니다

무료 한도를 넘었거나 요청이 몰린 경우입니다. 잠시 후 다시 시도하거나 Google AI Studio에서 사용량·결제 상태를 확인하세요.

시간 초과가 나옵니다

네트워크가 느리거나 서버가 바쁜 경우입니다. 입력한 내용과 완료된 결과는 보존되어 있으니 다시 시도하세요.

이미지의 상품 모양이 조금 다릅니다

AI 이미지는 완벽히 같지 않을 수 있습니다. 상품 사진을 여러 각도로 올리거나, 해당 이미지를 사진으로 교체하거나 AI 수정으로 보정하세요.

작업이 사라졌어요

작업은 이 컴퓨터의 자료 폴더에 저장됩니다. 상단 프로젝트에서 이전 작업을 열 수 있습니다.

8. 개인정보와 비용

  • 사진과 정보는 AI 생성·정리·검색·수정을 실행할 때에만 Google Gemini API로 전송됩니다.
  • Google에서 사용료가 청구될 수 있으며 요금은 Google 정책을 따릅니다. 이 프로그램은 요금을 받거나 대신 결제하지 않습니다.
