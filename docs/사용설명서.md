# 1. 이 프로그램은 무엇인가요?

상품 사진과 정보를 입력하면 AI(Google Gemini)가 **설명을 정리**하고 **상세페이지 문구와 연출 이미지**를 만들어 줍니다. 만든 결과는 블록별로 직접 고치고, 이미지를 바꾸거나 지운 뒤 **JPG로 저장**할 수 있습니다.

흐름: **상품 정보 입력 → 설명 정리 → AI 생성 → 미리보기 → 블록·이미지 편집 → 저장·내보내기**

> 직접 문구 수정, 순서 변경, 숨김·복원, 사진 교체, 저장·내보내기는 **API 키 없이도** 사용할 수 있습니다.

# 2. 설치

## 2.1 준비물

- Windows 10 또는 11 (64비트)
- 인터넷 연결(AI 기능 사용 시)
- Google Gemini API 키(AI 기능 사용 시) — [Google AI Studio](https://aistudio.google.com/apikey)에서 발급

Node.js 등 개발 도구는 **설치할 필요가 없습니다.** (설치 파일에 실행 환경이 들어 있습니다.)

## 2.2 설치하기

1. `DETAIL_PAGE_AI_Setup_v1.0.0.exe` 를 실행합니다.
2. **Windows 보호 화면(SmartScreen)** 이 나오면 [추가 정보] → [실행]을 누릅니다. 이 설치 파일은 코드 서명이 되어 있지 않을 수 있어 처음 실행할 때 경고가 보일 수 있습니다. (자세한 내용은 *배포 안내* 참고)
3. 안내에 따라 [다음]을 눌러 설치합니다. **관리자 권한은 필요 없습니다.** 기본 설치 위치는 `%LOCALAPPDATA%\Programs\DETAIL PAGE AI` 입니다.
4. 설치가 끝나면 바탕화면에 **DETAIL PAGE AI** 바로가기가 생깁니다.

## 2.3 실행하기

- 바탕화면 바로가기를 두 번 누르면 **기본 브라우저**에 프로그램 화면이 열립니다. (주소는 `http://127.0.0.1:47831` 처럼 이 컴퓨터 안에서만 쓰는 주소입니다.)
- 이미 실행 중이면 새로 띄우지 않고 **실행 중인 화면을 다시 엽니다.**
- 기본 포트가 다른 프로그램에 쓰이고 있으면 자동으로 다른 포트를 사용합니다.
- 창을 닫아도 프로그램은 백그라운드에서 계속 실행됩니다. 완전히 끝내려면 화면 오른쪽 위 **⋯ → 프로그램 종료**, 또는 시작 메뉴의 **DETAIL PAGE AI 종료**를 누르세요. 브라우저 창을 모두 닫은 뒤 20분이 지나면 자동으로 종료됩니다.

## 2.4 업데이트와 제거

- **업데이트**: 새 설치 파일을 그대로 실행하면 됩니다. 실행 중인 이전 버전은 자동으로 종료되고, **프로젝트와 업로드한 사진은 그대로 보존됩니다.**
- **제거**: Windows 설정 → 앱 → DETAIL PAGE AI → 제거. 제거할 때 *작업 자료도 삭제할지* 묻습니다. 기본값은 **[아니요]** 이며 자료는 `%LOCALAPPDATA%\DETAIL PAGE AI` 에 남습니다.

# 4. Gemini API 연결

1. 상단 **API 연결 안 됨** 버튼을 누릅니다.
2. Google AI Studio에서 발급한 API 키를 붙여넣고 **연결하기**를 누릅니다.
3. 연결되면 현재 사용 가능한 문구·이미지 모델이 자동으로 선택됩니다. (고급: 모델을 직접 고를 수 있습니다.)

**중요한 점**

- 키는 **프로그램이 켜져 있는 동안 컴퓨터 메모리에만** 보관됩니다. 저장 파일, 프로젝트 백업, 로그에는 남지 않습니다.
- 프로그램을 종료하면 키가 사라지므로 **다시 켤 때 새로 연결**해야 합니다.
- AI를 처음 쓸 때 **외부 전송과 사용료 안내**가 나옵니다. 입력한 정보와 사진이 Google로 전송되며, 사용량에 따라 **Google에서 별도 요금**이 청구될 수 있습니다. 동의해야 진행됩니다.
- 상세페이지 전체 생성은 **매번** 호출 횟수와 사용 모델을 보여 주고 확인을 받습니다.

# 5. 상품 정보 입력

| 항목 | 설명 |
|---|---|
| 상품명 | 필수 |
| 상품 설명 | 특징, 사용법, 구성 등을 자유롭게. 입력하지 않은 효능·인증·실적은 만들어 넣지 않습니다. |
| 타겟 고객 | 예) 아침을 거르는 30대 직장인 |
| 상품 사진 | **최대 5장, 장당 10MB**, JPG/PNG/WEBP. 끌어다 놓아도 됩니다. 큰 사진은 자동으로 적당한 크기로 줄여 저장합니다. |
| 선택 입력 | 가격, 구성·규격, 배송 조건, 프로모션 (입력한 것만 사용됩니다. 프로모션이 비어 있으면 프로모션 블록은 숨겨집니다.) |

## 5.1 AI로 정리

상품 설명 칸 위의 **AI로 정리**를 누르면 다음 6개 항목으로 정리합니다.

1. 상품 한눈에 보기 2. 핵심 특징 3. 구성·규격 4. 사용·보관 방법 5. 구매·배송 정보 6. 확인할 사항

- 결과는 **편집 가능한 미리보기**로 열립니다. 고친 뒤 **적용**하거나 **취소**합니다. 적용 후에도 **되돌리기**로 원래 설명으로 돌릴 수 있습니다.
- 입력한 **가격·수량·규격·배송 조건**은 그대로 보존합니다. 정리 과정에서 빠진 수치가 있으면 원문 그대로 ‘확인할 사항’에 남기고 알려 줍니다.
- 처리하는 동안 **상품명이나 설명을 바꾸면** 이전 요청의 결과는 자동 적용되지 않습니다.
- AI가 제안한 고객층은 문자열·목록 어떤 형태여도 읽을 수 있게 정리합니다. 고객층을 제안하지 않으면 **기존 타겟 고객 입력을 그대로** 둡니다.

## 5.2 정보 검색 · 사진 분석

- **정보 검색**: Google 검색을 사용해 공개 정보를 찾고 **요약과 출처**를 함께 보여 줍니다. 출처가 없으면 그 사실을 알려 줍니다.
- **사진 분석**: 올린 사진에서 **보이는 내용만** 정리합니다.
- 둘 다 *참고용*입니다. [상품 설명 끝에 추가]로 설명에 넣을 수 있으며, 사실 여부는 직접 확인해 주세요.

# 6. 상세페이지 만들기

1. **생성 모드**를 고릅니다. *일반*은 빠르고 가볍게, *고품질*은 더 정교하지만 사용료가 더 듭니다.
2. 연출 이미지도 만들지 선택합니다. (끄면 문구만 만듭니다.)
3. **AI로 상세페이지 만들기**를 누르고 안내를 확인한 뒤 동의합니다.
4. 진행 상황이 표시됩니다. 문구와 구성이 먼저 나타나고, 이미지가 하나씩 채워집니다. 중간에 **취소**할 수 있습니다.

기본 구성 블록은 **상품 정보 · 프로모션 · 대표 이미지 · 헤드라인과 고객 고민 · 감성·사용 장면 · 상품 소개 · 주요 특징 · 상품 화보 · 활용·사용 방법 · 디테일 · FAQ와 규격 · 구매 제안** 입니다.

- 상품의 카테고리와 분위기에 맞춰 **색감·문구·이미지 연출**이 달라집니다.
- 올린 상품 사진은 AI 이미지 생성의 **참고 자료**로 쓰이며, 상품 형태·포장·로고를 바꾸지 않도록 요청합니다. (AI 특성상 완벽히 같지 않을 수 있습니다. 해당 이미지는 직접 교체하거나 AI로 수정하세요.)
- **구매 제안**은 상품에 맞는 짧은 문구로 만들어집니다. 구매 링크가 없으면 결제가 되는 것처럼 보이지 않으며, 제목·설명·버튼 문구·링크는 모두 직접 고칠 수 있습니다.
- **실패해도 괜찮습니다.** 인증 실패, 사용량 초과, 시간 초과, 잘못된 응답은 이유를 알려 주고, 입력한 내용과 **이미 완료된 결과는 보존**됩니다. 일부 이미지만 실패하면 **실패한 이미지 다시 시도**로 이어서 만들 수 있고, 실패한 자리에는 올려 둔 원본 사진이 유지됩니다.
- **AI 없이 기본 구성만 만들기**: 입력한 내용만으로 블록을 채웁니다(API 불필요).

# 7. 편집

## 7.1 블록

각 블록 위 도구줄에서:

| 버튼 | 기능 |
|---|---|
| ▲ ▼ | 순서 이동 |
| 수정 | 문구를 직접 고침. **AI로 고치기**(예: “더 짧게”)도 가능 |
| 숨기기 / 복원 | 저장에서 제외 / 다시 포함 |

## 7.2 이미지

‘수정’ 서랍의 **이미지** 항목에서 이미지마다:

| 버튼 | 기능 |
|---|---|
| 사진으로 교체 | 내 컴퓨터의 사진 또는 입력해 둔 상품 사진으로 교체 |
| AI 수정 | 요청한 부분만 바꿈(예: “배경을 밝은 나무 테이블로”) |
| 다시 생성 | 같은 연출로 새로 만듦 |
| 삭제 / 복원 | 화면과 저장본에서 제외 / 다시 포함 |

이미지를 삭제해도 **다른 이미지 자리나 다른 블록은 영향을 받지 않습니다.**

## 7.3 색상 · 되돌리기

- **색상**: 상세페이지 결과물의 색을 바꿉니다. (프로그램 화면의 어두운 색과는 별개로, 결과물에는 적용되지 않습니다.)
- **되돌리기 / 다시 실행**(Ctrl+Z / Ctrl+Shift+Z): 문구 수정, 이미지 교체, AI 결과 적용 등을 한 단계씩 되돌립니다.

# 8. 저장과 내보내기

## 8.1 자동 저장

입력과 편집 내용은 **자동 저장**됩니다. 브라우저를 새로 고치거나 프로그램을 다시 실행해도 마지막 작업이 복원됩니다. 저장은 임시 파일에 먼저 쓴 뒤 교체하는 방식이라, 도중에 문제가 생겨도 이전 저장본이 손상되지 않습니다.

## 8.2 내보내기 (상단 **저장·내보내기**)

| 종류 | 설명 |
|---|---|
| 전체 상세페이지 **JPG** | 가로 860px(고해상도 선택 시 1720px). 세로가 매우 길면 여러 개 파일로 자동 분할 |
| 사용 중인 이미지 **ZIP** | 사용 중인 이미지만 담습니다 |
| 프로젝트 **JSON 백업** | 입력·편집 상태·이미지를 담습니다. **API 키는 포함되지 않습니다.** |
| 백업에서 복원 | JSON 백업을 새 프로젝트로 불러옵니다 |

**숨긴 블록과 삭제한 이미지는 JPG·ZIP에서 제외**됩니다. 편집 버튼과 이 프로그램의 안내 문구는 결과물에 들어가지 않습니다. JPG의 구매 버튼은 그림일 뿐 링크가 걸리지 않습니다. 구매 링크를 입력하면 ZIP에 `구매링크.txt` 로 함께 담깁니다.

## 8.3 프로젝트 관리

상단 **프로젝트**에서 새 프로젝트를 만들고, 이전 프로젝트를 열고, 삭제할 수 있습니다. 삭제는 데이터 폴더의 `trash` 폴더로 옮기므로 필요하면 직접 되살릴 수 있습니다.

# 10. 문제 해결

| 증상 | 해결 |
|---|---|
| “API 키가 올바르지 않습니다” | 키를 다시 복사해 붙여넣으세요(앞뒤 공백 주의). 키는 AI Studio에서 새로 만들 수 있습니다. |
| “사용량 한도를 넘었거나…” | 잠시 후 다시 시도하거나 Google AI Studio에서 사용량·결제 상태를 확인하세요. |
| “응답 시간이 초과되었습니다” | 네트워크 상태를 확인하고 다시 시도하세요. 입력과 완료된 결과는 보존되어 있습니다. |
| “Google 안전 정책으로 차단” | 문구나 사진을 바꿔 다시 시도하세요. |
| “이미지 모델을 찾지 못했습니다” | 해당 키로는 이미지 생성을 쓸 수 없습니다. ‘이미지도 함께 만들기’를 끄고 문구만 만들거나 다른 키를 사용하세요. |
| 화면이 열리지 않아요 | 바로가기를 다시 실행하세요. 계속 안 되면 시작 메뉴의 *DETAIL PAGE AI 종료* 후 다시 실행합니다. 이 프로그램은 외부 네트워크를 열지 않으므로(127.0.0.1 전용) 방화벽 허용이 필요하지 않습니다. |
| “프로그램과 연결이 끊겼습니다” | 프로그램이 종료된 것입니다. 바로가기로 다시 실행한 뒤 화면을 새로 고치세요. 작업은 자동 저장되어 있습니다. |
| “다른 창에서 변경되었습니다” | 같은 프로젝트를 두 창에서 열었을 때 나옵니다. 한 창만 남기고 새로 고치세요. |
| 사진이 안 올라가요 | JPG/PNG/WEBP, 10MB 이하인지 확인하세요. 최대 5장입니다. |

# 11. 주의
