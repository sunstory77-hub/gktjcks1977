## 4. 남은 문제와 위험

1. **실제 Gemini는 소량만 점검.** 일반·고품질 흐름은 한 번씩 성공했지만 사용량 초과·안전 차단·시간 초과·여러 사용자 환경은 실제로 겪어보지 못했습니다. 모델은 연결 시 `models.list` 로 고르므로 이름 변경에는 강하지만, 요청 형식이 바뀌면 해당 기능이 실패할 수 있습니다(실패 시 안내·재시도 제공). 판매 전 다른 계정·다른 환경에서 한 번 더 점검을 권합니다. `[기준: 2026-10 / 확인 필요]`
2. **실제 Windows 미검증(설치본의 AI 호출 포함).** 특히 (a) 설치 후 첫 실행 시 SmartScreen 경고, (b) `rundll32 url.dll,FileProtocolHandler` 로 기본 브라우저 자동 열기, (c) 한글 사용자 이름 경로, (d) 백신의 실시간 검사로 인한 파일 잠금(저장 재시도 로직 포함)을 실제 PC에서 확인해야 합니다.
3. **코드 서명 없음.** Windows 보호 화면 경고가 나올 수 있습니다. 배포 안내 참고.
4. **생성 도중 새로고침.** 서버 작업은 계속되지만 화면이 결과를 이어받지 못합니다(이미지는 저장되지만 페이지에 붙지 않음). 새로고침 전에 [취소]를 권장합니다.
5. **AI 이미지의 상품 동일성.** 프롬프트로 형태·로고 유지를 요구하지만 모델이 완벽히 지키지 못할 수 있어 사용자 확인이 필요합니다(안내 문구 포함).
6. **한 프로젝트를 두 창에서 편집** 하면 나중 창의 저장이 거부됩니다(덮어쓰기 방지, 안내 표시).
7. **JPG 가로 860px 고정**(고해상도 1720px). 오픈마켓별 규격(가로폭·용량·분할 높이)에 맞춘 프리셋은 없습니다.
8. 구매 버튼은 JPG 안의 그림이며 링크가 걸리지 않습니다(링크는 ZIP의 `구매링크.txt` 로 제공).
9. **설치 EXE 는 Linux 에서 NSIS 로 교차 빌드**했고 설치기가 64비트(amd64) 전용입니다. 32비트 Windows 는 지원하지 않습니다.
10. wine 시험은 Windows 와 완전히 동일하지 않습니다(위 0번 참고).
