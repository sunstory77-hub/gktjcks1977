## 2. 설치·실행 방식

- **사용자별 설치**(관리자 권한 불필요): `%LOCALAPPDATA%\Programs\DETAIL PAGE AI`
- 바탕화면 바로가기 → 실행기가 콘솔 창 없이 로컬 서버를 시작하고 **기본 브라우저**를 엽니다. 서버는 `127.0.0.1`(이 컴퓨터) 전용입니다.
- 사용자 자료: `%LOCALAPPDATA%\DETAIL PAGE AI` (설치 폴더 밖 → 업데이트·재설치해도 보존)
- 무인 설치: `DETAIL_PAGE_AI_Setup_v1.0.0.exe /S` (설치 위치 지정 `/D=C:\경로` — 반드시 마지막 인수)
- 무인 제거: `Uninstall.exe /S` (자료는 보존. 대화형 제거에서는 자료 삭제 여부를 묻고 기본값은 ‘아니요’)
- **업데이트**: 새 설치 파일을 실행하면 실행 중인 이전 버전을 먼저 종료하고 덮어씁니다.
- 구/신 버전이 동시에 있으면 새 실행본이 이전 실행본(다른 버전·다른 설치 위치)을 종료시키고 연결됩니다.

## 3. 코드 서명과 Windows 실행 경고

- **이 설치 파일과 실행기는 코드 서명되어 있지 않습니다.** 처음 실행하면 Windows **SmartScreen**(“PC를 보호했습니다”)이 나올 수 있고, 일부 백신이 알 수 없는 실행 파일로 경고할 수 있습니다. 고객 안내: [추가 정보] → [실행].
- 포함된 `node.exe` 는 Node.js 프로젝트가 배포하는 공식 파일이며 빌드 시 공식 체크섬(SHA-256)으로 검증합니다.
- 경고를 줄이려면 **코드 서명 인증서**로 설치 파일(`DETAIL_PAGE_AI_Setup_*.exe`)과 `DETAIL PAGE AI.exe`, `Uninstall.exe` 에 서명하세요(예: Windows SDK `signtool sign /fd SHA256 /tr <타임스탬프 서버> /td SHA256 …`). 인증서 종류(OV/EV 등)별로 SmartScreen 평판이 반영되는 방식과 비용·발급 절차는 정책이 자주 바뀌므로 구매 전에 최신 조건을 확인하세요. `[기준: 2026-10 / 확인 필요]`
- 배포 후 다수가 실행해도 서명이 없으면 평판이 쌓이기 전까지 경고가 계속될 수 있으니, 구매 안내 페이지에 위 고객 안내 문구를 넣는 것을 권장합니다.
- 백신 오탐이 보고되면 해당 백신 업체에 샘플 제출(오탐 신고)과 서명 적용으로 대응합니다.

## 4. 판매 전 확인할 것

1. **실제 Windows PC에서 설치→실행→API 연결→전체 생성→JPG 저장을 1회 이상** 점검하세요. 제작 환경에서는 실제 Gemini는 소량(Linux에서 1회) 점검했으나 **실제 Windows 설치본의 AI 호출은 확인하지 못했습니다**(검증 결과 문서 참고).
2. **이용 약관·환불·지원 정책**은 BAPI가 정해야 합니다. 설치기에 표시되는 `이용 안내`는 기술적 사실(외부 전송, 사용료 발생, 자료 위치, 서드파티 라이선스) 중심의 초안이며 법률 검토를 거친 약관이 아닙니다.
3. **API 키 정책**: 이 프로그램은 고객이 자신의 Gemini 키를 입력하는 방식(BYOK)입니다. 판매자가 키를 대신 제공·중계하려면 별도 서버·약관·요금 정책이 필요하며 현재 구조와 다릅니다.
4. **Google 요금·약관**은 고객의 Google 계정에 직접 적용됩니다. 판매 페이지에 “AI 사용료는 별도(Google에 지불)”임을 명시하세요. `[기준: 2026-10 / 확인 필요]`
5. **생성물 책임**: 상품 정보·표시광고·저작권·상표 확인은 사용자 책임임을 안내하세요(설치기·사용 설명서에 포함).
6. 다른 사이트의 코드·자산을 사용하지 않았습니다. 벤치마킹 시에도 해당 사이트의 소스·로고·문구·이미지를 가져오지 않도록 유지하세요.

## 5. 빌드·릴리스 절차

```bash
# 1) 버전 올리기: package.json 의 version (예: 1.1.0)
# 2) 시험
npm test && npm run test:e2e
# 3) 설치 파일 빌드 → dist/
npm run build:installer
# 4) 내용 점검
tests/verify-installer.sh
# 5) (권장) 코드 서명 → 체크섬 다시 계산 → 실제 Windows 에서 설치 시험
```

- 빌드 도구: NSIS 3.09(`makensis`), `curl`, `unzip`, `python3`+Pillow, `pandoc`. 번들 Node 버전은 `NODE_VER` 환경변수로 바꿀 수 있습니다(기본 22.22.0).
- 설치기·실행기는 64비트(`Target amd64-unicode`)입니다.
- 코드 구조: `src/`(서버·Gemini·저장소), `public/`(화면·렌더러), `build/`(NSIS·아이콘), `tests/`, `docs/`.
